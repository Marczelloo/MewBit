mewbeat Room lobby and minimized window

For approval before anything is built. The Room lobby takes on the Solo song select look: the same panels, rows and level tiles, plus a mode switcher, an Owner badge, and the level leaderboard. Sample data only. Mewbit is the existing still from this folder; the real stage uses the animated frames.

Try it: Ready, Player / Spectator, the level tiles and This server / Global work in both frames.

Screen 1 · Room lobby 1280 x 720

Left: the song on deck with the round clock and the owner's Start button, the queue, the four level tiles (these are also your difficulty picker, with stars, notes and your best), then the level leaderboard for the selected level, This server or Global, your row lit. Right: Mewbit, the players (owner first with a gold Owner badge, you with YOU, difficulty and ready state per player, spectators marked Watching), invite, key hints with Calibrate, and a bottom bar with Player / Spectator and Ready, like Play in Solo. Guests see the same lobby without Start now, and without the x on songs they did not add.
