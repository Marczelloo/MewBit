# mewbeat sound effects

All samples are CC0 (https://creativecommons.org/publicdomain/zero/1.0/). Credit is not required; it is here so a sound can be traced and swapped.

| File | Plays on | Source | Original file |
| --- | --- | --- | --- |
| `hit.wav` | key press, autoplay hit | Dustyroom Casual Game Sounds | `DM-CGS-32.wav` |
| `grade-high.wav` | results, grade S or A | Dustyroom Casual Game Sounds | `DM-CGS-08.wav` |
| `grade-mid.wav` | results, grade B or C | Dustyroom Casual Game Sounds | `DM-CGS-28.wav` |
| `full-combo.wav` | end of song, FULL COMBO | Dustyroom Casual Game Sounds | `DM-CGS-33.wav` |
| `tick.ogg` | each second of a countdown | Kenney Interface Sounds | `tick_004.ogg` |
| `go.ogg` | countdown reaches GO | Kenney Interface Sounds | `confirmation_002.ogg` |
| `complete.ogg` | end of song, SONG COMPLETE | Kenney Interface Sounds | `confirmation_004.ogg` |
| `tally.ogg` | results, each number appearing | Kenney Interface Sounds | `pluck_002.ogg` |
| `grade-low.ogg` | results, grade D | Kenney Interface Sounds | `error_006.ogg` |
| `miss.ogg` | a missed note | Kenney Impact Sounds | `impactPunch_medium_000.ogg` |

The Dustyroom files were reduced from 24-bit stereo to 16-bit mono and cut to their audible length; the Kenney files are unchanged.

- Dustyroom: https://dustyroom.com/free-casual-game-sounds/
- Kenney: https://kenney.nl/assets/interface-sounds, https://kenney.nl/assets/impact-sounds
